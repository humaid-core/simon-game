# Simon Game

A classic Simon Game built from scratch using HTML, CSS, JavaScript, and jQuery.

## 🎮 About the Project

This project recreates the popular Simon memory game. The game generates a sequence of colors and sounds, and the player must repeat the sequence correctly. With every successful level, the sequence becomes longer and more challenging.

## ✨ Features

* Random color sequence generation
* Interactive button animations
* Sound effects for each color
* Level progression system
* Game over detection
* Restart functionality
* High score tracking
* Responsive and clean user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* jQuery

## 🚀 How to Play

1. Press any key to start the game.
2. Watch the highlighted color carefully.
3. Repeat the sequence by clicking the colored buttons.
4. Each successful round adds a new color to the sequence.
5. Continue repeating the growing sequence.
6. The game ends when an incorrect color is selected.
7. Press any key to restart and try to beat your high score.
